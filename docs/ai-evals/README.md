# AI evaluation documentation

This directory is reserved for versioned AI evaluation cases and promotion evidence once an AI capability is implemented.

- Separate deterministic expected facts from qualitative scoring.
- Record model/provider, prompt version, dataset version, and evaluation date.
- Treat cross-tenant disclosure, invented financial evidence, and autonomous sensitive actions as release blockers.
- Never commit secrets, personal data, or raw supplier documents. Use synthetic or approved redacted fixtures.

No AI capability is part of Sprint 0.
